# プライバシーポリシー

**最終更新日: 2026年10月24日**

一般社団法人ヲタ芸協会（以下、「当協会」といいます）は、当協会が提供するスマートフォン用アプリケーション「Wotagei Cam」（以下、「本アプリ」といいます）における、ユーザーの個人情報の取り扱いについて、以下の通りプライバシーポリシー（以下、「本ポリシー」といいます）を定めます。

## 1. 取得する情報および利用目的

本アプリでは、ユーザーの個人情報を取得・利用する場面を以下に限定しています。

### ① カメラ・マイク・写真ライブラリへのアクセス、および動画データ
* **利用目的:** 動画の撮影、プレビューの表示、撮影した動画の写真ライブラリへの保存、およびギャラリー機能（ユーザーがアクセスを許可した範囲の写真ライブラリ内の動画の一覧表示・再生）の提供のため。
* **取り扱い:** 本アプリが扱う動画データは、ユーザーの端末内（ローカル）でのみ処理されます。本アプリが動画データを当協会のサーバーを含む外部へ送信することはありません。なお、ユーザーが iCloud 写真を有効にしている場合、以下の通り iOS の機能により Apple の iCloud との間で動画データがやり取りされます。
  * 本アプリで撮影し写真ライブラリに保存した動画は、iOS により iCloud と同期されます。
  * ギャラリー機能で iCloud 上にのみ保存されている動画を表示する場合、iOS の機能を通じて iCloud から端末へ取得されます。
* **アクセス許可の変更・動画の削除:** カメラ・マイク・写真ライブラリへのアクセス許可は、iOS の「設定」アプリから変更・取り消しできます。いずれかのアクセス許可を取り消した場合、本アプリの機能はご利用いただけません。撮影した動画は端末の写真ライブラリに保存されるため、削除は「写真」アプリから行ってください。

### ② お問い合わせ時にいただく情報
* **取得情報:** ユーザーが Google フォーム（ https://forms.gle/82zktmURVR8CPNmJ7 ）より入力した情報（メールアドレス、お問い合わせ内容等）。
* **利用目的:** お問い合わせへの回答、不具合の調査、およびアプリの改善のため。
* **保存期間・削除:** お問い合わせいただいた情報は、上記の利用目的に必要な期間保存し、不要となった場合は遅滞なく削除するよう努めます。ご自身の情報の削除を希望される場合は、お問い合わせフォームよりご連絡ください。

## 2. アカウント登録および外部ツールの利用について

* **アカウント登録:** 本アプリの利用にアカウント登録は不要です。
* **外部ツール:** 本アプリでは、データ分析や広告配信を目的とした外部ツール（サードパーティ SDK）は使用していません。

## 3. 個人情報の第三者提供

当協会は、お問い合わせ等を通じて取得した個人情報を、法令に基づく場合を除き、ユーザーの同意を得ることなく第三者に提供することはありません。

## 4. 法令、規範の遵守と見直し

当協会は、保有する個人情報に関して適用される日本の法令およびその他の規範を遵守し、本ポリシーの内容を適宜見直し、その改善に努めます。修正された最新のプライバシーポリシーは、本ページにて公開されます。
