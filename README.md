# プライバシーポリシー / Privacy Policy

**最終更新日 / Last Updated: 2026年5月30日**

一般社団法人ヲタ芸協会（以下、「当協会」といいます）は、当協会が提供するスマートフォン用アプリケーション「Wotagei Cam」（以下、「本アプリ」といいます）における、ユーザーの個人情報の取り扱いについて、以下の通りプライバシーポリシー（以下、「本ポリシー」といいます）を定めます。

The General Association of Wotagei (hereinafter referred to as "the Association") hereby establishes this Privacy Policy (hereinafter referred to as "this Policy") regarding the handling of users' personal information in the smartphone application "Wotagei Cam" (hereinafter referred to as "this Application") provided by the Association.

---

## 1. 取得する情報および利用目的 / Information Collected and Purpose of Use

本アプリでは、ユーザーの個人情報を取得・利用する場面を以下に限定しています。

This Application limits the collection and use of users' personal information to the following scenarios:

### ① カメラ・マイクへのアクセス、および動画データ / Camera, Microphone Access, and Video Data
* **利用目的 / Purpose:** アプリ内での動画撮影、プレビュー表示、およびギャラリー機能の提供のため。
* **取り扱い / Handling:** 本アプリで撮影された動画データは、完全にユーザーの端末内（ローカル）でのみ処理・保存され、当協会のサーバーを含む外部へ送信されることは一切ありません。
* **English:** Used for video shooting, preview display, and gallery functions within the Application. All video data captured are processed and stored strictly within the user's device (locally) and are never transmitted to external servers, including those of the Association.

### ② お問い合わせ時にいただく情報 / Information Provided via Inquiry Form
* **取得情報 / Collected Info:** ユーザーがGoogleフォーム（ https://forms.gle/82zktmURVR8CPNmJ7 ）より入力した情報（メールアドレス、お問い合わせ内容など）。
* **利用目的 / Purpose:** お問い合わせへの回答、不具合の調査、およびアプリの改善のため。
* **English:** Information (such as email address and inquiry details) entered by users via the Google Form. This information is used solely to respond to inquiries, investigate bugs, and improve the Application.

## 2. アカウント登録および外部ツールの利用について / Account Registration and Third-Party Tools

* **アカウント登録 / Account:** 本アプリの利用にアカウント登録は不要です。
* **外部ツール / Third-Party SDKs:** 本アプリでは、データ分析（Analytics）や広告配信（AdMob等）を目的とした外部ツール（サードパーティSDK）は一切使用していません。
* **English:** No account registration is required to use this Application. Furthermore, this Application does not use any third-party SDKs or tools for data analytics or advertising.

当協会は、お問い合わせ等を通じて取得した個人情報を、法令に基づく場合を除き、ユーザーの同意を得ることなく第三者に提供することはありません。

The Association will not disclose or provide personal information collected through inquiries to third parties without the user's prior consent, except as required by law.
